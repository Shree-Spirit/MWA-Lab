# Lab 07 - Async Function Execution

## Problem Statement

Implement an asynchronous JavaScript example that simulates a delayed task using `Promise` and `async/await`. The program should show a loading message, wait for a few seconds, and then display the final output.

## Important Points

- Use `async` and `await` for asynchronous code flow.
- Create a `Promise` that resolves after a timeout.
- Update the page content before and after the async operation.
- Understand how JavaScript handles delayed execution without blocking the main thread.
- Learn the difference between immediate execution and asynchronous behavior.

## Key Learning

This lab introduces asynchronous programming concepts and helps students understand the flow of time-based operations in JavaScript.
