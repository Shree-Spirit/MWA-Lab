# Lab 03 - Basic Calculator

## Problem Statement

Build a simple calculator application with number buttons and arithmetic operations. The user should be able to input numbers, perform addition and subtraction, and see the result using a basic evaluation logic.

## Important Points

- Use button click events to append numbers and operators.
- Maintain the current expression in an input field.
- Evaluate the expression using JavaScript.
- Implement a clear function to reset the display.
- Practice working with DOM events and interactive UI logic.
- Understand how basic browser-based calculators work.

## Key Learning

This lab focuses on event-driven JavaScript and building interactive UI components for arithmetic operations.
