# Lab 06 - Array Operations: Push, Pop, Shift, Unshift

## Problem Statement

Create a small JavaScript program that allows users to manipulate an array by adding elements and removing elements from different positions. The application should demonstrate the behavior of `push`, `pop`, `shift`, and `unshift` operations clearly.

## Important Points

- Store values in an array and update the display after each operation.
- Understand how `push()` adds an element at the end.
- Understand how `pop()` removes the last element.
- Understand how `shift()` removes the first element.
- Understand how `unshift()` adds an element at the beginning.
- Validate empty-array conditions before performing removal operations.
- Use DOM updates to show the result after each action.

## Key Learning

This lab develops array logic and demonstrates how data structure operations affect the arrangement and content of an array.
