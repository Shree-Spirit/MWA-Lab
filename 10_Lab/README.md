# Lab 10 - React Component Practice

## Problem Statement

Build a simple React page that demonstrates multiple reusable components such as paragraphs, inputs, buttons, and radio buttons. The application should present a basic login page with several UI elements arranged together.

## Important Points

- Break the user interface into small reusable components.
- Reuse props to customize component behavior and text.
- Practice passing styles and attributes into child components.
- Understand the role of components in React application structure.
- Learn how multiple UI elements work together in a single page.
- Improve readability and maintainability of frontend code.

## Key Learning

This lab reinforces component-based development, reusability, and the organization of UI logic in React applications.
