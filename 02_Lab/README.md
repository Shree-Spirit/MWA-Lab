# Lab 02 - Registration Form Validation

## Problem Statement

Create a registration form that collects the user's name, email, date of birth, and password. The program should validate the entered data and block invalid submissions with alert messages.

## Important Points

- Read values from HTML form inputs using JavaScript.
- Validate required fields before submission.
- Check whether the email follows a valid email format.
- Enforce password rules such as length and complexity.
- Use `alert()` to provide immediate feedback to the user.
- Understand the role of client-side validation in web forms.

## Key Learning

This lab teaches form validation, input checking, and how to improve the user experience by preventing invalid data entry.
