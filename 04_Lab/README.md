# Lab 04 - Vowel Counter

## Problem Statement

Develop a JavaScript program that takes a string as input and counts the total number of vowels in the text. The program should also display the count of each vowel individually (a, e, i, o, u) to help analyze the character frequency in the input string.

## Important Points

- Convert the input text into an array of characters.
- Traverse each character using loops.
- Check for vowel matches using conditional statements.
- Count both total vowels and individual vowel frequencies.
- Display results dynamically on the webpage using the DOM.
- Practice string handling and basic JavaScript logic.

## Key Learning

This lab introduces string processing, loop-based analysis, and dynamic result updates in the browser.
