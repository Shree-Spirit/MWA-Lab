# Lab 05 - String and Array Utility

## Problem Statement

Develop a JavaScript utility page that performs several string and array operations such as reversing text, sorting numeric arrays, and finding the minimum and maximum values from an input array.

## Important Points

- Convert input text into arrays using string methods.
- Reverse a string by iterating from the end to the beginning.
- Parse comma-separated values into numbers before sorting.
- Use loops to compute minimum and maximum values.
- Display results dynamically on the page using DOM updates.
- Work with arrays and common string manipulation operations.

## Key Learning

This lab strengthens string processing, array manipulation, and programmatic data analysis using JavaScript.
